1. O Dilema do Sobreajuste (Overfitting)

Um dos maiores riscos em ML é o modelo "decorar" os dados em vez de aprender o padrão real. Isso é chamado de Overfitting.

O modelo ideal captura a tendência (curva) sem tentar passar por cada ponto de ruído.

2. Data Leakage (Vazamento)

Acontece quando o modelo tem acesso a informações durante o treino que ele não terá no mundo real. É como ter o gabarito da prova.

Limiar (Threshold) de Decisão

Modelos de classificação geralmente retornam uma probabilidade (valor entre 0 e 1). O Limiar é o ponto de corte que converte essa probabilidade em uma classe final (Positivo ou Negativo).

Regra Padrão:

Se probabilidade > 0.5 (o limiar), classifique como Positivo.

Impacto na Matriz de Confusão:

Mudar o limiar para um valor mais baixo (ex: 0.3) aumenta o Recall (captura mais positivos reais) mas aumenta os Falsos Positivos (baixa Precisão).

Curva ROC (Receiver Operating Characteristic)

O que significa?

Mede o quão bem o modelo consegue distinguir classes em diferentes limites de decisão. Quanto mais perto a curva estiver do canto superior esquerdo (Area Under Curve - AUC alta), melhor o modelo é.

Eixo X: Taxa de Falso Positivo (FPR) | Eixo Y: Taxa de Verdadeiro Positivo (TPR)

Quando Usar Cada Métrica?

Acurácia é boa para classes balanceadas. Se as classes forem desbalanceadas (ex: 99% negativo, 1% positivo), use:

  • Precisão (Precision): Importante quando Falsos Positivos (FP) são caros.
  • Revocação (Recall): Importante quando Falsos Negativos (FN) são caros.
  • F1-Score: É a média harmônica entre Precisão e Revocação. É utilizada para resumir o desempenho em um único número, especialmente em casos desbalanceados.
  • AUC-PR: Representa a área sob a curva que relaciona a Precisão (eixo Y) e a Revocação (eixo X). Ideal para datasets desbalanceados, pois se foca no desempenho da classe minoritária (evento raro).

Conceito Fundamental: Resíduo (Erro)

O que é o Resíduo?

O resíduo é a distância vertical entre o ponto de dado real e a reta (ou curva) de previsão do modelo. Métricas de regressão (como RMSE e MAPE) são calculadas a partir desses resíduos.

Exemplo de métrica Absoluta

RMSE (Root Mean Square Error)

Mede a diferença média entre os valores previstos (ŷ) e os valores reais (y), dando mais peso a erros grandes. O resultado está na mesma unidade da variável alvo.

$$RMSE = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2}$$
Valor Exemplo: R$ 5.000,00

Significado: O erro típico do modelo é de R$ 5 mil.

Interpretação (Absoluta):

O RMSE é fácil de entender para o negócio (ex: "o erro é de 5 dias"). No entanto, ele não diz se esse erro é bom ou ruim sem o contexto do valor médio.

  • Problema: O erro absoluto (R\$ 5 mil) é excelente para prever o preço de um imóvel de R\$ 5 milhões, mas inaceitável para prever o preço de um imóvel de R\$ 50 mil.

Exemplo de métrica Relativa

MAPE (Mean Absolute Percentage Error)

Mede o erro médio como uma porcentagem, sendo útil para comparar modelos em diferentes escalas. É a métrica mais usada para benchmarks no mercado.

$$MAPE = \frac{100\%}{N} \sum_{i=1}^{N} \left| \frac{y_i - \hat{y}_i}{y_i} \right|$$
Valor Exemplo: 2.5%

Significado: O modelo erra em média 2.5% do valor real.

Interpretação (Relativa):

O MAPE resolve o problema de escala. Se o erro é de 2.5%, ele é bom tanto para imóveis caros quanto baratos.

  • Cuidado: MAPE tem problemas quando o valor real da variável alvo é zero ou muito próximo de zero (divisão por zero).
